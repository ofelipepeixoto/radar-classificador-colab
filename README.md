# Radar Classificador Colab

Laboratório educacional em português para criar e testar seu próprio classificador LoRA usando a GPU do Google Colab e o seu Google Drive. Seu computador usa apenas o navegador.

**Estado: em preparação. Ainda não é um tutorial homologado nem um modelo validado para atendimento real.**

A extração está na [PR #1 em rascunho](https://github.com/ofelipepeixoto/radar-classificador-colab/pull/1). O repositório de origem `radar-model-router` foi preservado. Nenhum peso ou arquivo privado do Drive é distribuído.

O exemplo classifica mensagens em categoria e urgência. Não é um chatbot. Os dados são fictícios e continuam sem aprovação humana. Antes de divulgar uma versão estável, faltam a homologação completa em outra conta/pasta nova e a resolução da combinação de dependências descrita na auditoria.
